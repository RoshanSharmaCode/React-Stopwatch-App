# React Stopwatch App

A simple stopwatch application built with React that allows users to start, stop, and reset a timer. The project demonstrates React Hooks, state management, and interval handling.

## Features

- Start the stopwatch
- Stop/Pause the stopwatch
- Reset the timer
- Real-time time updates
- Clean and responsive UI

## Technologies Used

- React.js
- JavaScript
- CSS
- Vite
